STSMN - ESP32 wiring guide

Smart Transformer Safety & Monitoring Network. Ye guide beginner ke liye hai: pehle saaman, phir diagram, phir pin-se-pin wiring.

Kul 8 modules: 6 sensor modules (1 Temperature, 2 Current, 3 Voltage, 4 Smoke, 5 Flame, 6 Water level) + 7 GPS + 8 SIM (SMS). Saath mein 3 output: Relay, Buzzer, 3 LED.

Pehle safety (zaroori)

  • Ye sirf low-voltage demo hai (battery / 3.7V - 12V). 230V mains ya asli transformer se kabhi mat jodo.
  • Wiring karte waqt ESP32 ka USB nikalo. Pehle sab jodo, phir jaancho, phir power do.
  • Relay ke load wale taar COM aur NO mein lagao (NC mein nahi): ESP32 band ho to supply kat jaaye.
  • SIM800L ka power ESP32 ke 3.3V ya 5V pin se mat lo: usse bahut current chahiye, ESP32 reset hoga.
  • Flame test ke time bade ki nigrani mein raho. Lighter sensor se 20 cm door rakho.

Code ESP32 mein kaise daalein

  1. Arduino IDE 2.x kholo. Boards Manager se ESP32 by Espressif Systems install karo.
  2. Library Manager se OneWire aur DallasTemperature install karo.
  3. File stsmn_single.ino poori kholo. Upar WIFI_AP_PASSWORD apna naya password (8-63 akshar) karo.
  4. ALERT_PHONE_NUMBER mein apna number daalo, country code ke saath, jaise +919876543210. Ye na badlo to SMS band rahega.
  5. Board: ESP32 Dev Module. Sahi COM port chuno. Upload dabao.
  6. Serial Monitor (115200) kholo. Dikhna chahiye: SMS alerts: ON aur kuch second baad SIM module ready.

Aam dikkatein

DikkatKaaran / hal
SIM module not answeringPower kam hai. Alag battery + 1000 uF capacitor lagao. GND common karo. TX/RX ulta to nahi (module TXD -> ESP GPIO 13).
SMS nahi aata, gsmRegistered falseSIM800L sirf 2G chalata hai. Aapke area mein 2G network (Airtel / Vi / BSNL) hona chahiye; Jio SIM nahi chalegi.
gpsFix falseAntenna ko khuli jagah rakho. Pehli baar fix mein 10 minute tak lag sakte hain. TXD -> GPIO 16 check karo.
ESP32 baar baar restartUSB adapter kamzor hai ya SIM800L ESP32 ke power se juda hai.
Current / voltage galatMultimeter se milaakar VOLT_CAL_FACTOR aur ACS712 ka divider check karo (config.h).

Sach batana (limits)

  • Ye code aur wiring asli hardware par abhi test nahi hue. Sirf computer par logic test aur syntax check hue hain. Pehli baar chalate waqt ek-ek module alag jaancho.
  • SMS mein location sirf tab aati hai jab GPS ka asli fix ho; warna likha aata hai GPS: no fix. Koi nakli location nahi bheji jaati.
  • Sensor ki limits (config.h) demo values hain; aapke sensors ke hisaab se calibrate karni hongi.
  • Ye educational demo hai, certified protection device nahi.
